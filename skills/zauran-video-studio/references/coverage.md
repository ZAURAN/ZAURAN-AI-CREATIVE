# Состав публичной поставки

Эта версия включает собственную оболочку, полные собственные навыки voice/AE, исследования, каталог метаданных и полный реестр источников. Чужие архивы/scripts/assets/licenses получаются целиком из закреплённых upstream snapshots по SHA-256. Исходный личный offline-комплект, описанный далее, сохранён неизменным и здесь не перепубликуется.

- 17 pinned репозиториев и 232 исходных repository SKILL paths остаются в индексе; по запросу скачивается полное дерево выбранного источника.
- 17 локальных provider skills, 383 Skillry records и 389 примеров остаются в каталоге со статусом requires_local_payload. Оригинальный наблюдавшийся доступ хранится отдельно. Полученные ранее байты подключаются через attach-payload; доступ к закрытым ZIP от этого не появляется.
- HyperFrames LFS registry содержит все 167 объектов и 170 путей с хешами/размерами. До fetch-lfs или подключения полного личного supplement медиа отсутствуют в публичном clone.
- Единственная включённая ZIP-библиотека — полные собственные published voice/AE skills. У них отдельные публичные папки в skills/; в общем навыке их инструкции загружаются из ZIP без повторной регистрации.
- verify проверяет целостность имеющихся файлов и отдельно сообщает ready/missing. Его успешный код возврата с ready=false не означает полученные внешние ресурсы или проверенный видеорендер.

## Проверки публичной версии

`python -m unittest discover -s scripts/tests -p "test_*.py"` запускает обе серии тестов: CLI, загрузку/хеши/размеры, cache, safe extraction, attached payloads и точное чтение документов. Метаданные каталога и новые/legacy skill paths проверяются CI. Snapshot и provider runtimes не запускаются во время тестов.

# Состав единого навыка

В оболочке один discoverable SKILL.md. Полные исходные SKILL.md и поддерживающие деревья сохранены в ZIP payload с оригинальными путями. ZIP использует обратимое архивирование байтов; исходные инструкции не сокращались, не объединялись с потерей правил и не заменялись пересказами.

Снимок базы содержит все 1574 исходных файла: JSON/CSV/SQLite, страницы и промпты, документы интеграции/обработки, 17 полных GitHub source archives. Каждый исходный файл сопоставлен с его архивной копией побайтно и по SHA-256. Отдельно сохранены 17 локальных Higgsfield-папок: 180 файлов/2695739 байт, включая references, agents metadata и иконки. Дубликаты сохранены: равный SKILL.md не гарантирует равный набор зависимостей.

249 source skill paths: 232 в репозиториях и 17 локальных. 383 записи Skillry: 41 полный публичный текст и 342 закрытых превью, 0 установочных ZIP. 389 gallery examples сохранены с исходными флагами promptPartial и URL. Framework README и собственные интеграционные справочники тоже доступны через индекс. Эти числа описывают сохранённые записи и пути, а не число уникальных независимых движков.

## Что требует внешнего доступа

Закрытые инструкции Skillry и bundle assets/scripts не были доступны в собранном материале. Сохранены сведения о них, не выдуманное содержимое. Model weights, внешние шрифты/стоки, runtime dependencies и provider credentials не устанавливаются и не включаются автоматически. Пользовательские секреты не упаковывались.

Исходный HyperFrames Git snapshot содержит 170 LFS pointer paths/167 объектов. Полный статус получения оригинальных объектов указан в lfs supplement manifest и preservation-report. Pointer сам по себе не является воспроизводимым видео или музыкой. При materialize полученные LFS bytes накладываются на их точные пути, исходные pointers остаются сохранены в неизменном repo archive.

LFS supplement получен полностью: 167 объектов, 170 путей, 567535998 исходных байт; SHA-256 и размеры проверены при скачивании, независимым проходом и проверкой итогового payload. Реальная materialize-проверка восстановила все 170 путей HyperFrames.

Symlink entries сохранены в исходных архивах. Materializer не создаёт и не следует таким ссылкам, а перечисляет их: часть относительных ссылок зависит от среды, а Talkcraft содержит абсолютную ссылку на node_modules машины автора. Source layout и обычные файлы извлекаются, но пропущенные links и недостающие runtimes должны быть разрешены по source инструкции до исполнения.

## Авторство и лицензии

Оригинальные license/notice/attribution файлы остаются рядом с источниками внутри архивов. Пакет не получает единую лицензию, отменяющую права каждого автора.

Снимки содержат в том числе Hypit с дополнительными коммерческими ограничениями, Talkcraft PolyForm Noncommercial, BRIA CC BY-NC, OpenMontage AGPL и отдельные licenses вложенных навыков; HyperFrames/SAM2/Shotcraft Apache notices, helper CC BY и ряд MIT проектов. В Remotion skills и корне ZAURAN license не обнаружен; локальные plugin skill-папки тоже не содержат отдельной лицензии. Для своего коммерческого использования или распространения проверять действующие документы автора, движка и весов. Этот личный собранный пакет не публикуется автоматически.

## Проверка

`python scripts/library.py verify` проверяет payload SHA-256/ZIP CRC и все перечисленные исходные файлы. Unit tests materializer проверяют layout, exact bytes, nested documents, отказы от traversal/overwrite/discovery roots и обработку symlinks. Forward tests проверяют выбор маршрута и сохранение контракта; они не являются benchmark качества видео. Рендеры, модели и чужие скрипты при сборке не запускались.

Воспроизводимые тесты: `python scripts/tests/test_library.py`. Итоговые измерения и результаты независимой проверки — в validation-report.json.
