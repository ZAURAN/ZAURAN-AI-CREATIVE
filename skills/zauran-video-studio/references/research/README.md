Код источников при получении не исполняется.

41 полный публичный текст Skillry и 342 превью были получены в личном снимке; установочных ZIP Skillry получено 0. Аналогично подключается локальный Higgsfield provider-пакет, если у пользователя есть доступ. SHA-256 страницы удостоверяет личный снимок, но не гарантирует получение тех же байтов сайта в будущем.

## Описание сохранённого личного снимка

Следующий документ сохранён полностью как описание **личного offline-комплекта**, его каталоги и SQL относятся к тому комплекту:

# База AI Video / Motion

Срез публичных данных Skillry и первичных репозиториев на 30 сентября 2026 года.

Откройте `catalog.html` для поиска без установки. JSON содержит полные извлечённые поля, CSV подходит для таблиц, SQLite — для запросов. `INTEGRATION.md` описывает подключение к ZAURAN; `BACKGROUND_REMOVAL.md` — обработку фото.

Собраны страницы всех 383 навыков каталога Skillry и 389 примеров галереи Opus: motion 223, interactive 68, 3d 51, explainer 47. Полные публичные тексты инструкций доступны для 41 навыка; 342 страницы дают только закрытые превью. Все 772 страницы получены без ошибок, покрытие сверено с sitemap, у каждой записи сохранены URL, время и SHA-256 исходной страницы.

В `skillry_documents/` лежат публичные инструкции и явно обозначенные PREVIEW.md. Это НЕ установочные ZIP: архивы, дополнительные assets, scripts и платные исходники пока не скачаны. Для них нужен вход и соответствующее право доступа. Список — `access-required.json`. Дополнительно в site_context/ сохранены тексты 15 остальных публичных страниц sitemap: инструкции установки, pricing, условия и Manus launch video. Все 787 URL sitemap получены; это не означает выгрузку ZIP или всех URL, которые сайт мог не перечислить.

В `source_documents/` сохранены Markdown из публичных репозиториев ZAURAN, Hypit и brag. Это справочные снимки, не полноценные установочные репозитории. URL авторов и лицензии остаются в исходниках; этот сборник не меняет лицензию каждого материала.

Тематики в поле `themes` вычислены по ключевым словам; отдельные ложные совпадения возможны. Наличие страницы или пометки сайта не доказывает качество монтажа. Навыки не запускались; видеорендеры и генерации не выполнялись. Сравнение инструментов в схеме является архитектурной рекомендацией по документации.
