# Уроки 3D/моушн-роликов: динамика и дефекты (обязательный чеклист)

Источник: реальный проект RolsBet Showreel 9:16 (three.js + HyperFrames, 15–16.10.2026).
Каждый пункт — дефект, который клиент увидел в готовом ролике. Формат: **симптом → причина → правило → проверка**.
Используй как каталог возможных дефектов для 3D/моушн-роликов. Применяй только проверки, относящиеся к выбранному движку и заказанному результату.

**Границы применения:** числовые значения, палитра, пропорции цвета, grade и композиционные решения ниже — исходные настройки проекта RolsBet, а не универсальные ограничения. В другом проекте приоритет у его брифа, брендбука, художественной задачи и фактического результата. «Обязательный grade-pass» относится к исходному ролику; в другом допустим иной grade или его отсутствие. Нулевые чёрные кадры проверяй как отсутствие неожиданных провалов рендера; намеренные затемнения и чёрные кадры по сценарию допустимы. Команды HyperFrames применяй только к HyperFrames, шейдерные рецепты three.js — только к соответствующему рендереру; AE и Remotion проверяй их средствами. Числа служат отправной точкой диагностики и требуют проверки на конкретном материале.

## 1. Засветы и экспозиция

- **Фон залит брендовым цветом** → аддитивный radial-glow с альфой 0.95 + цветной туман + сильные rim-источники.
  Правило: соблюдай пропорцию бренда (у RolsBet 80% графит / 20% красный). Фоновый glow ≤ 0.5 opacity, туман почти чёрный нейтральный, «дым» ≤ 0.1.
- **Белые пятна на объектах** (слот, экран, луч) → блум ловит поверхностные блики, эмиссив > 1.
  Правило: `UnrealBloomPass` threshold ≥ 1.1 (линейный HDR), strength ≤ 0.45, radius ≤ 0.35. Светиться должен только неон (`toneMapped: false`). Экраны и таблички — `MeshBasicMaterial` с цветом ≤ 1.0.
- **Точечные выжигания на золоте и лаке** → низкая шероховатость + сильный key.
  Правило: металл roughness ≥ 0.25, clearcoatRoughness ≥ 0.15, key-свет умеренный, красные софтбоксы в окружении не ярче ~3.6.
- **Объёмный луч — сплошной пересвеченный конус.**
  Правило: мягкие края по углу обзора (`pow(abs(dot(n, view)), 2.4)`), веер тонких лучей, пыль внутри, итоговый множитель ~0.5.
- **Красный засвет на рулетке** → отражение ярких красных полос окружения в лаке. Снижай яркость красных панелей окружения, а не материал.

## 2. Цветокор (отдельный проход после tone mapping)

Обязательный grade-pass в display-пространстве:
1. Тени уходят в нейтральный графит (десатурация теней ~0.58) — убирает «грязно-красный» в чёрном.
2. Тёплые блики (×(1.035, 0.99, 0.92) по маске light).
3. Soft shoulder над 0.82 по каналам, чтобы красный неон не клиппился в розово-белый.
4. Мягкий S-curve (0.2) и +12% насыщенности в средних тонах.
5. Виньетка, filmic floor.

Хроматическая аберрация в покое ≤ 0.0015, на свайпах ≤ +0.02.

## 3. Материалы: не «пластилин»

- **Однородные гладкие материалы читаются как пластилин.** Каждому классу поверхности нужны микро-карты (процедурные, сидированные, тайлящиеся):
  - золото — браш + царапины + разводы полировки (roughnessMap) и лёгкий bump;
  - лак — roughnessMap, `clearcoatRoughnessMap` с царапинами, `clearcoatNormalMap` («апельсиновая корка»);
  - дерево — кольца с fbm-искажением, bump ≤ 0.35, иначе выглядит как рябь на воде;
  - фетр — sheen + мелкий bump; фишки — глина (bump ≤ 0.3); карты — лён; барабаны — бумага; подарок — кожа;
  - короны — кованое золото (normalMap молотка).
- **Плоские отражения.** Окружение (PMREM) собирай из градиентного купола, полос-софтбоксов, потолочных световых полос и kicker-панели. Иначе металл не играет.
- **`ExtrudeGeometry` из SVG** даёт UV в единицах пути (сотни). Нормализуй UV в 0..2, иначе карты повторяются сотни раз.
- **Мелкие золотые детали выглядят тёмным деревом** (стойка монитора) → браш-рельеф на маленьких боксах. Для них `goldBright`, `RoundedBoxGeometry`, bumpScale ≤ 0.3.

## 4. Мерцание и алиасинг (самый частый брак)

- **Монеты «искрят» на свету** → 128 жёстких насечек на ребре, резкий рельеф R (bumpScale 6), карта царапин на маленьком объекте. Получаются субпиксельные блики, которые блум раздувает.
  Правило: для мелких на экране объектов (монеты, пипсы, кубики, фишки) — без карт царапин:
  - roughness ≥ 0.34;
  - рельеф размыт (canvas `filter: blur(5px)`);
  - насечки синусоидальные, ≤ 48 штук;
  - bumpScale ≤ 2.2 на аверсе и ≤ 0.5 на ребре;
  - сферы-пипсы ≥ 20×14 сегментов.
- **Яркость и цвет объектов «кипят»** → зерно 0.028, новое в каждом кадре, в тенях даёт ±25–30% к пикселю.
  Правило: зерно ≤ 0.012 и взвешено по яркости: `grain * (0.35 + L)`.
- **Ореолы прыгают при движении камеры** → блум в половинном разрешении. Правило: блум в полном разрешении кадра.
- **Стробоскоп кольца/подиума** → вспышка на каждое событие (23 падения подряд, амплитуда 0.25, затухание 10/с).
  Правило: импульс на событие ≤ 0.07, затухание ≈ 4/с. Сильная вспышка — только на одно ключевое событие.
- **Проверка:**
  - 6 соседних кадров (шаг 1/30 с): mean|ΔL| региона и ряд средней яркости;
  - на статике шаг ≤ 1–2 уровня;
  - большие скачки допустимы только на краях движущихся объектов.

## 5. Чёрные кадры из-за NaN в шейдерах

- **Весь 3D-слой чёрный на части таймлайна** → `pow(1.0 - vUv.y, k)` с отрицательной базой (интерполяция даёт vUv > 1). Получается NaN, блум размазывает его на весь кадр.
  Правило: база `pow` всегда в `clamp(…, 0.0, 1.0)`. `pow(x, 2.0)` заменять на `x*x`. Невидимые объекты (scale 0.001) скрывать через `visible = false`.
- **Проверка:**
  - в браузере рендер каждые 0.1 с, ищем кадры почти целиком нулевые;
  - по готовому MP4: `ffmpeg … signalstats` → YAVG по всем кадрам, тёмных кадров 0;
  - диагностика: выключи блум. Если кадр ожил — ищи NaN-пиксель.

## 6. Появление текста и типографика

- **Обрывки букв до появления текста** → маска-ревил `yPercent + skewY`: наклон поднимает край широкой строки над маской `overflow: hidden`.
  Правило: в стартовом состоянии всегда `opacity: 0` (и yPercent ≥ 130), анимируй к `opacity: 1`.
- **Лого видно на кадре 0** → скрытие через `tl.set(…, 0)` не рендерится на t=0. Правило: начальное скрытое состояние — в CSS.
- **Дёрганый letterSpacing** → снапится к пикселям. Правило: вместо него `scaleX` + `blur`.
- **Красный текст на красном свечении** (контраст 2.5:1) → локальный радиальный тёмный скрим под копирайтом, контраст ≥ 3:1 для крупного текста. Скрим появляется и уходит вместе с текстом.
- **Каунтеры цифр** считай от времени `hf-seek`, а не от `onUpdate` GSAP: при seek события подавляются. Ставь `font-variant-numeric: tabular-nums`.
- **Плашки разъезжаются на 3 ряда** → задай `max-width` колонки и подбери кегль/паддинги под сетку 2×2.

## 7. Безопасные зоны 9:16 (TikTok / Reels / Shorts)

- Зона 1080×1920: **сверху 250, снизу 400 (текст ≤ y 1520), слева 72, справа 140** (колонка кнопок).
- Центрированные блоки — в полосе x 140–940 (ширина ≤ 800).
- Внутрь попадает **весь текст**: HTML, неон-вывески в 3D, плашки (PROMOCODE), лого. Охранное поле лого — ½ его высоты.
- Не уменьшай шрифт: перекадрируй 3D камерой. Отодвинь камеру (`d ≥ 2637 / (px на единицу)` при fov 40) и опусти target, чтобы объекты встали между лого и копирайтом.
- **Проверка:** накладывай рамку зоны на кадры **из готового MP4**, включая моменты до появления текста.

## 8. Переходы и камера

- **Вертикальный свайп показал пустое чёрное «небо».** Правило: используй pan или roll-свайп. Фоновая плоскость шире кадра с запасом на поворот камеры.
- Все времена резов — одни константы для камеры и для видимости объектов (без «22.9 против 23»).
- Объекты не должны пролетать перед лого и плашками у самого края охранного поля. Траекторию и высоту подъёма подбирай под зону.

## 9. Бренд и контент (RolsBet и любые клиентские ролики)

- Палитра, шрифты и логотипы — только из брендбука и оригинальных файлов. Лого не перерисовывать; 3D-короной можно делать match-cut в плоское лого.
- Офферы и цифры без подтверждения клиента — переменные шаблона с пометкой «заглушка». В тексте ролика не выдумывать.
- Сторонние логотипы платёжек не использовать: только нейтральные названия и иконки.

## 10. Техника рендера (Windows / HyperFrames)

- `ENAMETOOLONG` на длинном пути → держи проект по короткому пути. Временно — `subst X:` на **родительскую** папку: Studio не видит проект в корне диска.
- Пин CLI в `package.json` обновляй до latest (`upgrade --project .`) и проверяй `check`.
- Тяжёлая процедурная сборка (карты, PMREM, компиляция шейдеров) — через `window.__hf.buildReady`.
- После перемещения проекта проверь, что файлы реально скопировались. При необходимости копируй сам (`robocopy /E`, код 1 = успех).

## Чеклист перед выдачей (всё обязательно)

- [ ] Фон графитовый, акцент ≤ 20%, нет белых выжиганий на объектах.
- [ ] Grade-pass включён, тени нейтральные, красный не клиппится.
- [ ] Материалы с микро-картами, мелкие объекты — гладкие (без искр).
- [ ] Зерно ≤ 0.012, блум в полном разрешении, нет стробоскопа.
- [ ] Все `pow` с clamp, 0 чёрных кадров (браузерный прогон + signalstats по MP4).
- [ ] Текстовые ревилы с `opacity: 0` на старте, 0 обрывков до анимации.
- [ ] Весь текст и лого внутри safe zone (рамка на кадрах из MP4).
- [ ] `hyperframes check`: 0 ошибок, контраст AA.
- [ ] ffprobe: разрешение, fps, число кадров, длительность; контакт-лист из MP4 просмотрен.
