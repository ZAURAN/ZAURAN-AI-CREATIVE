# Визуальный атлас: типографика и композиция

18 выбранных кадров из исследовательских референсов. JPG-файлы не включены в публичный пакет. Ниже сохранены описания, ожидаемые имена файлов и ссылки на оригинальные публичные видео; отсутствие файла отмечено в `manifest.json` как `image_available: false`. Для визуального осмотра открой источник на указанной отметке времени доступным средством либо используй изображение, предоставленное для текущего проекта. Ссылка или описание не заменяют реальный просмотр. Кадры являются визуальными примерами, не готовыми ассетами для вставки в клиентский ролик. Названия шрифтов не установлены. SaaS-кадры 360p, часть Reels — небольшие storyboard-превью с учебным окружением; их точность ограничена.

## Как применять

1. По индексу выбрать 2–4 кадра под текущую задачу.
2. Реально открыть файлы изображений доступным vision-инструментом. Один путь или подпись не означает, что кадр просмотрен.
3. Указать, что именно заимствуется: роль текста, выравнивание, масштаб относительно кадра, контраст, расположение относительно человека/UI.
4. Разработать собственную типографическую спецификацию под реальный текст: начертание, размер, интерлиньяж, трекинг, переносы, поля, контраст. Предложенные числа не выдавать за измерения оригинала.
5. Приложить выбранные кадры к передаче в ZAURAN AI DEV либо явно дать доступные ему файлы. Локальные пути этого компьютера не считаются автоматически доступными другой нейронке.
6. Составить ТЗ с ID кадров и различием «взять / не переносить». Если vision недоступен — назвать ограничение, не заявлять визуальное сравнение.
