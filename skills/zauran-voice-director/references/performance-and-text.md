# Исполнение, произношение и текст

Ниже — наши производственные приёмы, не гарантии ElevenLabs. Технический синтаксис см. в [elevenlabs.md](elevenlabs.md).

## Актёрская задача

На смысловой отрезок определи адресата, цель и тактику: успокоить партнёра, скрыть страх, добиться ответа, удержать внимание. Затем вырази это слышимой манерой. «Грустный, радостный, злой, кинематографичный» одновременно не задаёт исполнимой задачи. Поворот намерения важнее тега перед каждым словом.

В карточке голоса фиксируй CHAR_ID, voice ID, язык/акцент, тембр, расстояние подачи, ритм, интенсивность и отличия от других героев. Визуальный паспорт не даёт оснований придумывать реальный voice ID. Голос повторяющегося героя — версионируемый ассет; эмоция сцены — состояние.

Используй уже заданные сценой цель/тактику/подтекст. Для глубокого актёрского разбора доступен `tig-acting-task.md`: в репозитории относительно этого файла — `../../../references/tig-acting-task.md`, при установке соседними скиллами — `../../zauran-ai-creative/references/tig-acting-task.md`. Используй существующий путь; не загружай его ради одного ударения.

## Три слоя

- `SOURCE_TEXT`: авторское написание, версия и исходная пунктуация.
- `SPOKEN_TEXT`: что должно быть услышано, без технических тегов; подстановки прозрачны.
- `TTS_TEXT`: произносимый текст с синтаксисом модели, без поясняющих абзацев и таймкодов.

Буквальные скобки и косые черты исходника не удаляй слепым regex как «служебные». Различай авторский текст, ремарку для постановки и вставленный нами тег. В аудиокниге слова автора могут быть частью чтения; в сценарии фильма ремарки обычно не озвучиваются — роль фрагмента берётся из задания.

## Русский и смешанные языки

| Случай | Решение |
|---|---|
| `2026`, `15%`, `3,5`, `10–12` | Определи значение и падеж: год, количество, диапазон, дробь; подготовь произносимую форму |
| `01/02`, `1.500`, артикул или номер | Не угадывай неоднозначное значение; уточни фрагмент или оставь помеченным |
| Бренд, фамилия, топоним | Переиспользуй утверждённое произношение; неизвестное обозначь |
| `все/всё`, омографы | Сохрани смысл; `ё` и ударение добавляй только по понятному контексту |
| Иностранное название | Не переводить автоматически; язык произношения определяется брифом |
| Аббревиатура | Названия букв, цельное слово и раскрытие термина не всегда взаимозаменяемы |

«На 15%» → «на пятнадцать процентов» сохраняет значение. «Доставка за 24 часа» → «быстрая доставка» меняет утверждение и не является нормализацией. Нельзя исправлять длительность такой заменой без разрешённой редакторской задачи.

Для неизвестного ударения выясни требуемое звучание или используй надёжный словарь. Не сочиняй IPA ради заполнения поля. Слушай важное слово и отдельно, и внутри реальной фразы.

## Пример: спокойный рекламный VO

Условный оригинальный пример, не результат синтеза. Eleven v4; русский; обращение к одному слушателю, уверенно и без напора. Описательный тег ниже — кандидат для короткого теста.

SOURCE_TEXT и SPOKEN_TEXT одинаковы:

> Иногда достаточно одного шага. Открой дверь. Остальное начнётся само.

Поле синтеза:

```text
[warm, conversational voice] Иногда достаточно одного шага. [pause] Открой дверь. Остальное начнётся само.
```

Нейтральная альтернатива для сравнения — тот же текст без тегов. Смех, вдохи и многоточия не добавляются автоматически ради выразительности.

## Пример: два героя

Контекст для исполнителя: Анна хочет узнать правду; Илья скрывает испуг. Голоса выбираются в полях участников UI/dialogue, а не в произносимой строке.

Анна — блок её назначенного голоса:

```text
[curious] Ты видел, кто оставил ключ?
```

Илья — блок его назначенного голоса:

```text
[quiet, restrained voice] Нет. Я только что пришёл.
```

Вторая режиссёрская формулировка экспериментальная. Подтекст «он лжёт» не добавляется как произносимая фраза. Нужное перекрытие дорожек требует монтажной проверки, а не обещания точного тайминга от тега.

## Диагностика

| Наблюдение | Следующая изолированная проверка |
|---|---|
| Речь ровная, нет намерения | Сверить выбор голоса, затем один локальный акцент/тег |
| Переигрывание | Убрать противоречивые указания; сравнить с нейтральным вариантом |
| Голос изменился | Проверить voice ID, модель, версию клона, настройки |
| Читаются инструкции | Убрать служебный текст; проверить синтаксис |
| Вместо манеры появился SFX | Указать именно качество голоса |
| Не помещается реплика | Измерить речь и паузы; проверить допустимость монтажной перестройки |
| Ошибка только на стыке | Перегенерировать смысловой фрагмент с доступным контекстом |
| Неверное имя | Проверить требуемое звучание, затем одну подстановку/словарь/IPA |

Повтор того же дефекта без новой гипотезы — повод пересмотреть способ исполнения, а не бесконечно нажимать Generate. Число попыток ограничено разрешённым объёмом.
