# ElevenLabs: контракт модели и источники

Проверено 2026-09-29. Это снимок документации, не результат прослушивания нашей генерации. Перед новым API-интегрированием, миграцией или спорной возможностью перепроверь указанную страницу и реальные поля среды. Поиск может отдавать старый текст: 29 сентября выдача ещё называла v3 основной моделью, хотя открытые страницы уже описывали v4. Если web-reader не открывает страницу, допустим прямой публичный HTTP GET; ошибка одного инструмента не доказывает отсутствие продукта.

## Выбор

| Модель | Когда рассматривать | Граница |
|---|---|---|
| `eleven_v4` | Основной кандидат для рекламы, персонажей, рассказа и готового видео | Проверять конкретный голос; одобренный тембр не мигрировать молча |
| `eleven_v4_turbo` | Разговорный агент, интерактивная речь с малой задержкой | Низкая задержка не задаёт творческий приоритет для готового ролика |
| `eleven_v3` | Продолжение проекта с выбранной v3, сравнительный тест или недоступность v4 | Собственный контракт; не обобщать его на всю платформу |
| `eleven_multilingual_v2` | Существующий процесс v2, альтернативный дубль для сравнения | Без v4-аудиотегов; SSML/словарь сверять отдельно |

### Что подтверждает страница запуска

[Eleven v4](https://elevenlabs.io/v4): более 90 языков, до 10 000 символов одной генерации, контекстное соединение длинных фрагментов, диалоги и аудиотеги, поддержка PVC. Старые IVC/PVC предлагается переобучить под v4. Заявления об устойчивости между дублями — обещания поставщика; они не заменяют нашу проверку. Длинный проект планируется по смысловым фрагментам, а не одним неограниченным запросом.

### Настройки v4

[Страница модели](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/eleven-v4): обе версии v4 используют **Stability** и **Similarity**. Ни Style, ни Speed, ни SSML для v4 не поддерживаются. Уменьшение Stability повышает вариативность, увеличение делает исполнение устойчивее. Большая Similarity сильнее привязывает к референсу и может уменьшать естественность. На другом языке v4 стремится к естественному акценту целевого языка; заданный иностранный акцент тестируется отдельно. Чистота исходника клона влияет и на перенос дефектов записи.

Наш порядок настройки: начни с текущих значений выбранного голоса в конкретной среде, запиши их, меняй по одному параметру после прослушивания. «50/75 подходит всем», ползунок Speed для v4 и Speaker Boost как обязательный контроль — невалидные советы. Не выдавай числовой диапазон или пресет UI за API-значение без проверки шкалы.

### Разметка v4

По [Best practices](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices): аудиотеги задаются в квадратных скобках; примеры — `[whispers]`, `[curious]`, `[sighs]`. Теги могут трактоваться как эффект вместо манеры, поэтому указывай именно слышимое качество голоса. Для трудного слова доступна нативная IPA-запись `/…/`; транскрипцию и ударение проверяй, затем тестируй с выбранным голосом. SSML `<break>` для v4/v3 не используй.

Рабочая конвенция: минимально достаточная разметка на смене намерения, нейтральный вариант без тегов как основа сравнения. `[pause]` и `[long pause]` задают характер паузы, не гарантированную длину. Собственные описательные теги — кандидаты для проверки, а не официальный перечень команд. КАПС, многоточия и усиление пунктуации могут изменить смысл подачи; исходный сценарий остаётся отдельным.

### Русский текст и словари

[Руководство TTS](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech) рекомендует устранять неоднозначность чисел и символов словами. Поддержка языка не доказывает правильность каждого русского ударения. `ё`, падеж числительного, однозначная расшифровка аббревиатуры и проверка названия полезнее слепой глобальной транслитерации. Ударение знаком или заглавной буквой — только проверяемая гипотеза для конкретного голоса, не универсальный синтаксис.

Словарь произношений подключай реальным механизмом проекта/интерфейса. XML словаря не вставляй в произносимое поле TTS. У alias сохраняй значение слова; для v4 при необходимости сначала проверь нативный IPA. Не переносить англоязычные SSML phoneme-рецепты v2 на русский v4.

## Диалог, контекст и API

Перед рабочим payload прочитай текущие [Convert](https://elevenlabs.io/docs/api-reference/text-to-speech/convert) и, для нескольких участников, [Create dialogue](https://elevenlabs.io/docs/api-reference/text-to-dialogue/convert). Проверь model ID, формат speaker inputs, лимиты и контекст именно endpoint. Выбор модели в TTS не доказывает её поддержку в dialogue. При расхождении документации и хоста назови ограничение; отдельные дорожки могут быть вариантом в рамках брифа.

Локальная карточка задания не является API JSON. Не выдумывай поля `emotion`, `director_prompt`, `duration` или параметр контекстного соединения. Служебный контекст идёт через поддерживаемый механизм; дописанная в TTS строка «Предыдущая сцена…» может быть произнесена. Сохраняй IDs запросов/контекста, когда инструмент их возвращает. Seed, если существует в endpoint, не гарантирует идентичный файл.

Проверенные различия endpoint на дату снимка:

- **TTS Convert:** `voice_id` в пути; текст в `text`, настройки в `voice_settings`. Контекст: `previous_text`/`next_text` либо `previous_request_ids`/`next_request_ids` (до трёх IDs с каждой стороны; IDs имеют приоритет над соответствующим текстом). Явно указывай нужный `model_id`: документированный default — v2. Не считай общую схему voice_settings доказательством поддержки Speed/Style в v4.
- **Dialogue:** `inputs` — пары `text` и `voice_id`, до десяти уникальных голосов; рекомендованный суммарный объём текста — до 2000 символов на запрос. Настройки идут в `settings`. Контекст называется `previous_text`/`future_text`, до 100 символов каждый; не все модели его поддерживают. Документированная модель по умолчанию — v3. Лимит 10 000 со страницы v4 не переносится автоматически на dialogue.
- В обоих запросах документированы до трёх `pronunciation_dictionary_locators`. Возможности модели/хоста перепроверяются при запуске. Общая схема и рекламная поддержка multi-speaker ещё не гарантируют конкретный режим перекрытия реплик.

Проверяй model ID и возможности по [List models](https://elevenlabs.io/docs/api-reference/models/list), не только по интерфейсному названию. Не запрашивай ключ для текстовой подготовки; при API используй локальный секрет без печати. Цена, доступность формата и права плана выясняются перед расходом, а не закрепляются навсегда.

## Альтернативная актёрская опора

[Voice Changer](https://elevenlabs.io/docs/overview/capabilities/voice-changer) — отдельный маршрут преобразования записанного исполнения. Рассматривай его, когда пользователь дал или хочет записать точную подачу; TTS-теги не гарантируют воспроизведение сложного ритма. Это смена производственного маршрута, а не скрытая замена исходного голоса.

## Не подтверждено нашим тестом

Качество русского акцента конкретного голоса; срабатывание каждого тега; IPA конкретного имени; отсутствие артефактов; длительность; сохранность голоса после миграции. Эти свойства получают статус проверки только после получения и прослушивания соответствующего аудио.
