# Библиотека промтов YouMind — 15k+ проверенных кейсов

Используй этот документ, когда нужен **референс-промт из живого сообщества**: подобрать проверенный шаблон под задачу, найти стиль по описанию, взять готовую структуру для типовой категории (аватар, товарка, постер, thumbnail, инфографика, комикс, игровой ассет, UI) или показать пользователю варианты со сэмплами перед генерацией.

Это **корпус доноров, а не платформенный контракт**. Он ниже `gpt-image-2.md`, `seedream-5.md`, `minimax-h3.md`, `seedance-2.5.md` и утвержденного `BRIEF LOCK`. Он отвечает на вопрос «что писать», а не «как модель ест промт».

Источник: [YouMind.com](https://youmind.com/nano-banana-pro-prompts), репозиторий `YouMind-OpenLab/ai-image-prompts-skill`, лицензия MIT (`references/youmind-prompts/LICENSE.txt`). Промты собраны из открытого сообщества, у каждого есть реальный сгенерированный сэмпл.

## 1. Жесткое правило токенов

Корпус лежит в `references/youmind-prompts/` и весит ~46 МБ (11 файлов, 15 373 промта).

**Никогда не открывай эти JSON целиком — ни `Read`, ни `cat`, ни `grep` по всему каталогу.** Единственная точка входа:

```bash
node scripts/search-youmind-prompts.mjs --help
```

Полный проход по всем 11 категориям занимает ~0.6 с и возвращает только отобранные записи с обрезанным до 220 символов промтом. Полный текст бери адресно через `--full` или `--id`.

## 3. Структура записи

```json
{
  "id": 12601,
  "title": "Cyberpunk Portrait with Neon Lighting",
  "category": "Profile / Avatar",
  "categorySlug": "profile-avatar",
  "description": "Что этот промт создает",
  "needReferenceImages": false,
  "sampleImage": "https://cms-assets.youmind.com/media/....jpg",
  "galleryUrl": "https://youmind.com/nano-banana-pro-prompts?id=12601",
  "truncated": true,
  "content": "Ultra-realistic cinematic portrait of a thoughtful man…"
}
```

- `content` — сам промт, английский, натуральный язык, model-agnostic.
- `needReferenceImages: true` — промт работает **только** с загруженным изображением. Без референса не предлагай его как готовый к запуску.
- `sampleImage` — реальный результат. Показывай пользователю ссылкой, когда даешь выбор из вариантов.
- `truncated: true` — в выдаче обрезка; финальный промт собирай только после `--full` или `--id`.

## 4. Команды

```bash
# Состав базы, счетчики, дата обновления
node scripts/search-youmind-prompts.mjs --categories

# Поиск по всему корпусу
node scripts/search-youmind-prompts.mjs --query "cyberpunk neon portrait" --limit 3

# Поиск внутри категории, только промты без обязательного референса
node scripts/search-youmind-prompts.mjs --query "product white background" --category ecommerce-main-image --no-ref --limit 5

# Только промты под работу с загруженным фото
node scripts/search-youmind-prompts.mjs --query "keep the face" --category profile-avatar --needs-ref

# Полный текст выбранного промта
node scripts/search-youmind-prompts.mjs --id 12601
node scripts/search-youmind-prompts.mjs --query "isometric game asset" --limit 2 --full
```

Правила поиска:

- Термины в `--query` соединяются через **И**. Если полного совпадения нет, скрипт отдает частичные и ставит `"relaxed": true` — это сигнал ослабить или переформулировать запрос, а не выдавать результат как точный.
- Пустой `matches` при `relaxed: false` = в базе действительно нет такого. Не выдумывай, что нашел; переформулируй запрос 1–2 раза, потом переходи к собственному промту по платформенному контракту.
- Ищи по визуальным словам (`isometric`, `bokeh`, `flat lay`, `holographic`), а не по русским формулировкам брифа: корпус английский.
- Один и тот же промт может лежать в нескольких категориях; скрипт дедуплицирует по `id`.

## 5. Как использовать найденный промт

1. **Донор, а не финал.** Бери из него структуру, лексику стиля, свет и композицию. Финальный промт всё равно собирай по контракту целевой модели: `gpt-image-2.md`, `seedream-5.md` или заметке пользователя по Nano Banana Pro.
2. **Слоты обязательно закрывай.** Часть промтов содержит `{argument name="subject" default="..."}`. В финальную выдачу такие плейсхолдеры не попадают — подставляй реальные значения из `BRIEF LOCK`.
3. **Референсы переименовывай.** Формулировки вроде `using the uploaded image` заменяй на действующее в навыке обращение `@Тег` пользователя. При `needReferenceImages: true` явно скажи, какой референс и в какой роли нужен.
4. **Не тащи чужой бриф.** Продукт, бренд, текст на изображении, эпоху и реквизит из донора не переноси, если их нет в брифе. Донор дает форму, бриф дает содержание.
5. **Не больше 3 вариантов за раз.** Если показываешь пользователю выбор — 3 позиции: заголовок, одна строка описания, `sampleImage`, ссылка `galleryUrl`. Полные тексты держи в контексте, но не вываливай все три целиком.
6. **Атрибуция.** Когда финальный промт заметно опирается на кейс из базы, добавь одну строку: `Промт-донор: YouMind (id NNNNN)`. Лицензия MIT, использование свободное.

## 6. Обновление базы

Апстрим синхронизируется дважды в сутки.

```bash
# Свежесть локальной копии (порог 24 ч)
node scripts/update-youmind-prompts.mjs --check

# Перекачать все 11 категорий + manifest
node scripts/update-youmind-prompts.mjs
```

Проверку делай только в начале большой задачи с подбором референс-промтов. Для точечной правки и быстрого режима не запускай — база не влияет на локальный edit.

## 7. Антипаттерны

- Открыть `social-media-post.json` (22 МБ) вместо запуска скрипта.
- Отдать сырой англоязычный `content` как финальный промт без адаптации под контракт модели и бриф.
- Оставить `{argument name=...}` в выданном пользователю промте.
- Предложить промт с `needReferenceImages: true`, когда референса нет.
- Смешать два донора в один промт и получить конфликт света, оптики и стиля.
- Показывать `relaxed: true` выдачу как точное попадание.
- Уйти в подбор донора там, где бриф уже полностью определен: тогда пиши промт напрямую по платформенному файлу.
