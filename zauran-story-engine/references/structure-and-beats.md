# Структура и бит-лист

## Выбор каркаса

Книжная альтернатива — `book-methods.md`: причинное развитие по Труби и дополнительная проверка по Снайдеру. Выбери подход по задаче, не накладывай все схемы одновременно. Термин «Кадр» в предоставленном переводе Макки обозначает обмен действиями/реакциями внутри сцены (beat), а не монтажный шот нашего шот-листа.

Донорские описания шести каркасов с примерами таймингов 15/30/60 с — `donors/storytelling-frameworks.md` (Serge Shima, CC BY 4.0). Это варианты анализа, не обязательные правила. Проценты, количества и категоричные формулировки донорского текста не отменяют формат и ограничения пользователя. Краткая таблица выбора:

| Задача | Каркас | Почему |
|---|---|---|
| Собрать причинный сюжет | **Story Spine** (Pixar) | Помогает проверить связи поступков и последствий |
| Изменение поведения, манифест, «было/стало» | **Sparkline** (Duarte) | контраст боль/возможность нарастает |
| Эмоциональный сюжетный ролик ≥30 с | **Freytag** | Помогает организовать нарастание и развязку |
| Прямой отклик, донат, CTA сейчас | **Monroe** | ведёт к действию, не к чувству |
| Имиджевая кампания, бренд-проводник | **Hero's Journey** (StoryBrand) | клиент герой, бренд помогает |
| Сквозной сериал | Каркас эпизода + дуга сезона по замыслу | Последствия соединяют эпизоды |
| Самостоятельная серия / антология | Каркас отдельной истории или повторяемая механика | Общая интрига необязательна |
| Любой готовый сценарий | **Pixar-фильтр** (7 правил) | пост-проверка, не структура |

При заметном использовании ставь строку `Каркас: <название> (Serge Shima, creative-director-skill, CC BY 4.0)`.

## Тайминг под AI-производство

Бит — смысловой шаг; сцена — непрерывная ситуация; шот — монтажная единица. Один бит может занимать несколько шотов, одна сцена — несколько битов. Длительность шота выбирай по действию, речи и паузе. Таблица ниже — примеры быстрого монтажа, не лимиты AI-моделей и не обязательное количество:

| Хронометраж | Шотов | Битов | Что помещается |
|---|---|---|---|
| 6 с | 2–3 | 1 | один хук + один переворот |
| 15 с | 5–8 | 3 | конфликт → следствие → развязка (Story Spine строки 3–7) |
| 30 с | 10–15 | 5 | полный каркас, экспозиция ≤ 5–7 с |
| 60 с | 20–30 | 6–8 | цепочка следствий 4–5 звеньев, каждое — сцена |
| Эпизод 20–40 с в серии | по ритму | по задаче | самостоятельный результат или продвижение сквозного сюжета (`short-form-series.md`) |

Речь: 2.5–3 слова/с — стартовая оценка для быстрой подачи, не норматив языка. Вычти из общей длины паузы и немые действия; оцени слова по оставшемуся времени. Без записи не заявляй точный хронометраж. Проверь, совпадают ли интервалы битов и шотов с общей длиной и помещаются ли реплики. VO может дополнять изображение или намеренно противоречить ему.

## Бит-лист

```md
# BEATS — [название] · [формат] · [хронометраж]
Каркас: [...]
Логлайн: [...]

| # | Время | Бит (что происходит) | Что меняется | Наблюдаемое действие / образ | Звук / VO (функция) |
|---|---|---|---|---|---|
| 1 | 0–2 с | хук: [...] | статус-кво → трещина | [образ] | [тишина / SFX / первая фраза] |
| 2 | 2–6 с | [...] | [...] | [...] | [...] |
| … | | | | | |
| N | …–конец | финал: [конкретный кадр] | новая норма | [образ + CTA/продукт если по брифу] | [...] |

Инварианты между битами: [герой, локация, реквизит, свет, время суток]
```

Правила:

- Укажи изменение или функцию бита: ожидание, ориентация, ритм, подготовка, последствие. Если функции нет, предложи убрать.
- Опиши, что зритель увидит/услышит. Бит может включать несколько образов или действий; не заменяй их абстрактным выводом.
- Продукт появляется только там, где это прописано в STORY LOCK; не автоматически в конце.
- Финал — конкретный кадр и точный текст CTA, если он нужен.

## Тест структуры

1. Что теряется при удалении бита: причинность, информация, эмоция, ориентация или ритм?
2. Предсказуемость финала мешает обещанному опыту или усиливает ожидание? При необходимости перестрой от последствия к причине.
3. Начало создаёт интерес в выбранном темпе?
4. Есть ли момент, который зритель перескажет одной фразой?
5. Для серии: соблюдён тип связи и есть содержательная вариативность?
6. Для соцсетей: полезна ли проверка без звука для выбранного формата (`short-form-series.md`)?

## Дальше

Утверждённые биты → сцены. Бит с конфликтом двух воль или с выбором героя пишется через Scene Engine (`scene-to-shotlist.md` § «Сцена»). Бит-перебивка (establishing, монтажная вставка) — сразу в шот.
