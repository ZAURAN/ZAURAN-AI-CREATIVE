# Структура и бит-лист

## Выбор каркаса

Полные описания шести каркасов с таймингами 15/30/60 с — `donors/storytelling-frameworks.md` (Serge Shima, CC BY 4.0). Краткая таблица выбора:

| Задача | Каркас | Почему |
|---|---|---|
| Быстро собрать любой формат, гарантировать причинность | **Story Spine** (Pixar) | «because of that» не даёт случайных поворотов |
| Изменение поведения, манифест, «было/стало» | **Sparkline** (Duarte) | контраст боль/возможность нарастает |
| Эмоциональный сюжетный ролик ≥30 с | **Freytag** | без кульминации не запомнят |
| Прямой отклик, донат, CTA сейчас | **Monroe** | ведёт к действию, не к чувству |
| Имиджевая кампания, бренд-проводник | **Hero's Journey** (StoryBrand) | клиент герой, бренд помогает |
| Серия эпизодов / вселенная | Story Spine на эпизод + сквозная Sparkline или Freytag на сезон | эпизод закрыт, сезон тянет |
| Любой готовый сценарий | **Pixar-фильтр** (7 правил) | пост-проверка, не структура |

При заметном использовании ставь строку `Каркас: <название> (Serge Shima, creative-director-skill, CC BY 4.0)`.

## Тайминг под AI-производство

AI-ролик = короткие шоты по 1–3 секунды, каждый меняет состояние кадра. Считай бюджет шотов заранее:

| Хронометраж | Шотов | Битов | Что помещается |
|---|---|---|---|
| 6 с | 2–3 | 1 | один хук + один переворот |
| 15 с | 5–8 | 3 | конфликт → следствие → развязка (Story Spine строки 3–7) |
| 30 с | 10–15 | 5 | полный каркас, экспозиция ≤ 5–7 с |
| 60 с | 20–30 | 6–8 | цепочка следствий 4–5 звеньев, каждое — сцена |
| Эпизод 20–40 с в серии | 8–18 | 4–5 | свой хук, свой переворот, крючок в следующий |

Речь: ≈2.5–3 слова в секунду для RU/UA, с воздухом на паузы. 15 секунд ≈ 30–35 слов максимум; если действие уже показывает смысл, VO не повторяет его.

## Бит-лист

```md
# BEATS — [название] · [формат] · [хронометраж]
Каркас: [...]
Логлайн: [...]

| # | Время | Бит (что происходит) | Что меняется | Что видит зритель (одним образом) | Звук / VO (функция) |
|---|---|---|---|---|---|
| 1 | 0–2 с | хук: [...] | статус-кво → трещина | [образ] | [тишина / SFX / первая фраза] |
| 2 | 2–6 с | [...] | [...] | [...] | [...] |
| … | | | | | |
| N | …–конец | финал: [конкретный кадр] | новая норма | [образ + CTA/продукт если по брифу] | [...] |

Инварианты между битами: [герой, локация, реквизит, свет, время суток]
```

Правила:

- Колонка «Что меняется» обязательна для каждого бита. Бит без изменения — вычеркнуть.
- Колонка «Что видит зритель» — один образ, не описание. Если образа нет, бит объясняет, а не показывает.
- Продукт появляется только там, где это прописано в STORY LOCK; не автоматически в конце.
- Финал — конкретный кадр и точный текст CTA, если он нужен.

## Тест структуры

1. Убери любой бит — цепь до финала рвётся? Если нет, бит лишний.
2. Финал известен до середины? Пиши от конца к началу.
3. Первые 2 секунды — образ, а не подводка?
4. Есть ли момент, который зритель перескажет одной фразой?
5. Для серии: каждый эпизод закрывает свой вопрос и открывает следующий?

## Дальше

Утверждённые биты → сцены. Бит с конфликтом двух воль или с выбором героя пишется через Scene Engine (`scene-to-shotlist.md` § «Сцена»). Бит-перебивка (establishing, монтажная вставка) — сразу в шот.
