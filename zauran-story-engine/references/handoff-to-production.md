# Handoff в производство (zauran-ai-creative)

Скилл заканчивается на утверждённых сценарных артефактах. Промты под модель, выбор модели/среды, генерация, QA — `zauran-ai-creative`. Handoff = пакет файлов, из которого производственный скилл собирает BRIEF LOCK без вопросов к пользователю.

## Пакет

```text
<проект>/
  STORY_LOCK.md          — из story-routes.md
  CANON.md               — если мир повторяется
  PASSPORT_<имя>.md      — на каждого повторяющегося героя
  BEATS.md               — бит-лист с таймингом
  SCRIPT_vN.md           — шот-сценарий с реестром требований
  VO_vN.md               — текст + режиссура (если есть речь)
  REFERENCES.md          — роли референсов (ниже)
  NOTES.md               — журнал (learning-loop.md)
```

## REFERENCES.md — контракт ролей

```md
| Файл / тег | Роль (ровно одна) | Что брать | Что НЕ переносить |
|---|---|---|---|
| @Герой_turnaround | персонаж | лицо, волосы, одежда | фон, свет |
| @Кухня_hero | локация | геометрия, материалы | людей, реквизит |
| @Грейд | стиль | палитра, контраст, зерно | архитектуру, объекты |
| @Продукт | продукт | форма, лого, цвет | руки, упаковку-соседа |
```

Один референс — одна роль. Теги — как в инструменте пользователя, `@Тег` дословно.

## Маппинг в BRIEF LOCK производственного скилла

| zauran-ai-creative ждёт | Берётся из |
|---|---|
| что делаем, формат, цель | STORY_LOCK |
| что сохранить / что изменить / что запрещено | CANON §2–3, §6; STORY_LOCK «Запрещено» |
| герой, локация, продукт | PASSPORT §A, CANON §4, §6 |
| шоты, камера, свет, звук, инварианты | SCRIPT_vN |
| роли референсов | REFERENCES.md |
| модель и среда генерации | **не решает этот скилл** — гейт в `intake-and-brief.md` производственного скилла |

## Перед handoff

1. Director's review из `story-routes.md` пройден.
2. Каждый шот SCRIPT_vN содержит камеру (термин словаря), свет, инварианты, «что меняется».
3. Описание героя во всех шотах — один и тот же текст.
4. Реестр требований сверен: каждое `active` есть в тексте.
5. Файлы лежат в проектной папке, ссылки в ответе кликабельны.

## Что не обещать

Длительность клипа, lip-sync, число референсов, физика, разрешение — свойства конкретной модели. Скилл истории пишет «шот 1 — 2 с»; сможет ли модель дать ровно 2 с — проверяет производственный скилл по своему платформенному файлу.
