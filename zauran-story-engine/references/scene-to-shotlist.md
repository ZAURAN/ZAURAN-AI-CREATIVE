# От сцены к шот-сценарию

## Сцена

Драматическая сцена (герой хочет, что-то мешает, он действует, что-то переворачивается) пишется и проверяется через **Tig's Scene Engine**: Goal → Obstacle → Tactic → Reversal → Value Shift. Используй модуль как инструмент разбора, сохраняя выбранный тип драматургии и ограничения пользователя:

- От папки этого reference-файла: `../../references/tig-scene-engine.md`. Не привязывайся к домашнему каталогу Claude.
- Если файла нет: сформулируй цель, конкретное препятствие, действие/тактику, ответ ситуации и изменение положения/знания. Для глубокого разбора — `screenwriting-craft.md`.

Для драматической сцены проверь связь цели с историей, реальность препятствия, мотив тактики и вызванное ею последствие. Поворот может изменить степень, знак или понимание ценности. Если сдвига нет, проверь функцию сцены, не добавляй искусственный переворот. Наблюдение, пауза и атмосферный монтаж допустимы по замыслу.

Для нескольких персонажей в одном пространстве — позиции, взгляды, траектории по **Blocking Map** (`../../references/tig-blocking-map.md`). Для игры — **Acting Task** (`../../references/tig-acting-task.md`). Если модулей нет, явно задай позиции, направления взглядов и движений, действие и реакцию.

Бит без конфликта (establishing, перебивка, product-shot) в Scene Engine не гонять — сразу шот.

## Шот-сценарий — SCRIPT_vN.md

```md
# [Название] — [формат], [хронометраж]
Версия: vN · Story lock: [дата] · Каркас: [...]

**Логлайн:** одно предложение — что меняется в ролике.

## Шот 1 — [0–2 с]
**Картинка:** конкретное действие, план, место. [CHAR_<имя>@vN; состояние/одежда/реквизит сцены]
**Камера:** траектория или статичный кадр — термин из словаря (`shot-vocabulary.json`); сложное движение помечено для проверки производством.
**Свет:** мотивированный источник (окно, лампа, вывеска, небо).
**Звук / VO:** только нужное. Функция: hook / пояснение / эмоция / CTA.
**Инварианты:** что обязано совпасть с соседними шотами.
**Меняется / функция:** [изменение, реакция, ориентация, ожидание или ритм]

## Шот 2 — [2–5 с]
...

**Финал:** конкретный кадр и точный текст/CTA, если нужен.

## Реестр требований
| # | Требование | Источник | Статус |
|---|---|---|---|
| R1 | [...] | явная команда / утверждённый файл | active |
```

Правила:

- У шота одна ясно описанная монтажная задача. Для простого производства предпочтительна одна траектория камеры; непрерывное сложное движение допустимо, если нужно замыслу, с пометкой для проверки производством. Не дели шот автоматически по числу движений.
- Герой указан по ID и версии паспорта; состояние сцены отделено от постоянных признаков. Передай точный паспорт с пакетом.
- В производственном шот-листе камера указана явно, включая static, чтобы намерение было однозначным; это не гарантия поведения генератора.
- В непрерывном действии состояния стыкуются. При смене времени, места или точки зрения обозначь монтажный переход, если без него возникнет неоднозначность.
- Реестр с v1: active / blocked / removed по `project-vault.md`; несовместимость означает blocked, а не разрешение удалить требование.

## Режиссёрская конкретика

Вместо оценочных слов — наблюдаемая причина и эффект:

| Вместо | Писать |
|---|---|
| «кинематографично» | план, движение камеры, источник света, палитру |
| «премиально» | материалы, чистоту кадра, контраст, контролируемые блики |
| «драматично» | блокинг, тени, паузу, приближение камеры |
| «герою грустно» | взгляд вниз, напряжение челюсти, замедление движения |
| «красивый интерьер» | геометрию, материалы, направление света, допустимый реквизит |
| «напряжение растёт» | slow push in, сокращение планов, тишина перед звуком |

Материалы — через поведение света: матовое дерево — мягкие рефлексы, металл — чёткие блики, стекло — отражения и преломление.

## Словарь

`references/shot-vocabulary.json` — ≈100 терминов (движение камеры, крупность, ракурс, оптика, свет, композиция, стиль, цвет, атмосфера, негатив) с полями «что делает / когда применять / сила». Ищи:

```bash
node scripts/search-shot-vocabulary.mjs --query "orbit"
node scripts/search-shot-vocabulary.mjs --cat "Свет" --power Сильно
node scripts/search-shot-vocabulary.mjs --cats
```

Где у термина есть `phrase` — это готовая английская формулировка для промта, бери её в handoff дословно. Внешние справочники того же рода: aicameramovements.com (углы и движения с примерами), cineprompt.io (конструктор под Kling/Veo/Sora/Runway) — только как справка, не как источник контрактов моделей.

## Continuity-инварианты (минимум)

Для каждого перехода между шотами перечисли, что совпадает: герой (паспорт §A), локация (CANON §4 / location passport), реквизит и его положение, свет и время суток, направление взгляда/движения (не пересекать ось без причины), состояние продукта. Смена локации может быть обычной склейкой; отдельный переходный шот нужен, если несёт смысл или помогает ориентации. Не навязывай движение камеры каждому переходу.
