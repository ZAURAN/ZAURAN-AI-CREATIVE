# От сцены к шот-сценарию

## Сцена

Драматическая сцена (герой хочет, что-то мешает, он действует, что-то переворачивается) пишется и проверяется через **Tig's Scene Engine**: Goal → Obstacle → Tactic → Reversal → Value Shift. Определения там авторские, применять как написано:

- в репо: `../../references/tig-scene-engine.md`
- локально: `~/.claude/skills/zauran-ai-creative/references/tig-scene-engine.md`

Causal audit обязателен для каждой сцены перед шотами: цель — звено в цепи к финалу истории; препятствие реально угрожает (не просто «стоит дорого»); тактика — разумная догадка героя; переворот меняет знание/положение; ценность сдвинулась (было +/−, стало −/+).

Для нескольких персонажей в одном пространстве — позиции, взгляды, траектории по **Blocking Map** (`tig-blocking-map.md` там же). Для игры — **Acting Task** (`tig-acting-task.md`).

Бит без конфликта (establishing, перебивка, product-shot) в Scene Engine не гонять — сразу шот.

## Шот-сценарий — SCRIPT_vN.md

```md
# [Название] — [формат], [хронометраж]
Версия: vN · Story lock: [дата] · Каркас: [...]

**Логлайн:** одно предложение — что меняется в ролике.

## Шот 1 — [0–2 с]
**Картинка:** конкретное действие, план, место. [герой — дословный блок из PASSPORT §A]
**Камера:** один ход или статичный кадр — термин из словаря (`shot-vocabulary.json`).
**Свет:** мотивированный источник (окно, лампа, вывеска, небо).
**Звук / VO:** только нужное. Функция: hook / пояснение / эмоция / CTA.
**Инварианты:** что обязано совпасть с соседними шотами.
**Меняется:** [одна вещь, которая другая к концу шота]

## Шот 2 — [2–5 с]
...

**Финал:** конкретный кадр и точный текст/CTA, если нужен.

## Реестр требований
| # | Требование | Источник | Статус |
|---|---|---|---|
| R1 | [...] | пользователь / референс / гипотеза | active |
```

Правила:

- Один шот = одно движение камеры и одно изменение. Два движения — два шота.
- Персонаж описывается **дословно одним и тем же текстом** в каждом шоте, где он есть.
- Камера пишется явно всегда, включая `static shot / locked-off camera` — иначе генератор добавит движение сам.
- Первый кадр каждого шота должен быть достижим из последнего кадра предыдущего (или объявлен монтажной склейкой).
- Реестр требований ведётся с v1; правка дополняет, не заменяет; `removed` только по явной команде или при физической несовместимости.

## Режиссёрская конкретика

Вместо оценочных слов — наблюдаемая причина и эффект:

| Вместо | Писать |
|---|---|
| «кинематографично» | план, движение камеры, источник света, палитру |
| «премиально» | материалы, чистоту кадра, контраст, контролируемые блики |
| «драматично» | блокинг, тени, паузу, приближение камеры |
| «герою грустно» | взгляд вниз, напряжение челюсти, замедление движения |
| «красивый интерьер» | геометрию, материалы, направление света, допустимый реквизит |
| «напряжение растёт» | slow push in, сокращение планов, тишина перед звуком |

Материалы — через поведение света: матовое дерево — мягкие рефлексы, металл — чёткие блики, стекло — отражения и преломление.

## Словарь

`references/shot-vocabulary.json` — ≈100 терминов (движение камеры, крупность, ракурс, оптика, свет, композиция, стиль, цвет, атмосфера, негатив) с полями «что делает / когда применять / сила». Ищи:

```bash
node scripts/search-shot-vocabulary.mjs --query "orbit"
node scripts/search-shot-vocabulary.mjs --cat "Свет" --power Сильно
node scripts/search-shot-vocabulary.mjs --cats
```

Где у термина есть `phrase` — это готовая английская формулировка для промта, бери её в handoff дословно. Внешние справочники того же рода: aicameramovements.com (углы и движения с примерами), cineprompt.io (конструктор под Kling/Veo/Sora/Runway) — только как справка, не как источник контрактов моделей.

## Continuity-инварианты (минимум)

Для каждого перехода между шотами перечисли, что совпадает: герой (паспорт §A), локация (CANON §4 / location passport), реквизит и его положение, свет и время суток, направление взгляда/движения (не пересекать ось без причины), состояние продукта. Переход между локациями — отдельный шот с явной механикой (pass-through, whip pan, склейка по движению).
