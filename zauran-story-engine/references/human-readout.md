# READOUT — один PDF для человека, .md — для ИИ

## Правило

Первая выдача сценария / ТЗ по проекту (и каждая новая мажорная версия vN) = **один файл** `READOUT_<проект>_vN.pdf` в папке проекта. Пользователь или клиент читает только его. Все `.md` (STORY_LOCK, CANON, PASSPORT, BEATS, SCRIPT, VO, REFERENCES, NOTES, STATE) — рабочие файлы для ИИ; на них ссылаться, но не просить человека их читать. Отдельные PDF на каждый .md не делать.

Провал, который правило закрывает (2026-09-04, Loio): 10 отдельных PDF, пользователь спросил «какой из папки главный сценарий, чтобы глазами пробежаться».

## Что внутри, в этом порядке

1. **Обложка**: проект, версия, дата, что это (эпизод / ролик / серия), кто заказчик, статус (черновик / на утверждение).
2. **Одной страницей** — концепт для клиента (CONCEPT, на языке клиента).
3. **STORY LOCK** — формат, цель, аудитория, тон, обязательное, запрещённое, рубрика оценки, SERIES SCALE (для серии).
4. **Сценарий по битам** — таблица BEATS: время · что происходит · что видит зритель · звук/реплика.
5. **Шот-сценарий** — SCRIPT_vN целиком (картинка, камера, свет, звук, что меняется).
6. **Речь** — VO/диалог с режиссурой.
7. **Следующие эпизоды** — EPISODES (если серия).
8. **Что нужно от заказчика / открытые вопросы** — список решений и материалов (логотип, голос, внешность героя, дедлайн).
9. **ТЗ на производство** — коротко: сколько шотов, каких планов, SFX, музыка, субтитры, экспорты, лимит генераций, что в манифест.

Язык: как у клиента/пользователя (RU по умолчанию), концепт — на языке сдачи (EN, если бриф EN). Ссылки на модели, промты, среды генерации — не в READOUT (это производство).

## Как собрать

```bash
python scripts/build-readout.py --out "<папка>/READOUT_<проект>_v2.pdf" --title "<Проект> — v2" \
  CONCEPT_*.md STORY_LOCK.md BEATS.md SCRIPT_v2.md VO_v2.md EPISODES.md OPEN_QUESTIONS.md
```

Скрипт склеивает .md в один HTML с обложкой, оглавлением и разрывом страницы между документами и печатает через headless Chrome/Edge. Требует `pip install markdown` и установленный Chrome или Edge. Разделы 8–9 пишутся отдельным коротким `OPEN_QUESTIONS.md` / включаются в STORY_LOCK — не выдумывать, брать из реестра требований и §9 CANON.

## Когда пересобирать

- Каждая версия SCRIPT_vN → новый `READOUT_vN.pdf` (старый не удалять).
- Точечная правка одного шота без смены версии — не пересобирать, пока пользователь не попросит PDF.
- В финальном ответе — одна ссылка на READOUT первой строкой; ссылки на .md — ниже, помеченные «для ИИ».
