# Бриф, идея и проверка истории

## Сначала известное

Извлеки формат, длину, аудиторию, цель, героя, мир, тон, обязательное и запреты. Отмечай источники: пользователь / утверждённый файл / референс / предложение. Не превращай детали референса в требования автоматически.

Для теста или тендера перенеси заданную рубрику с весами в бриф. Проверь покрытие требований; не заявляй гарантированные баллы от заказчика.

## STORY LOCK

В разработке и производственном пакете фиксируй кратко. Если пользователь уже поручил писать по брифу, переходи к черновику без повторного «делай». Статус «утверждено» ставь только при явном подтверждении; разрешение написать черновик не означает утверждение содержания.

```md
## STORY LOCK
- Статус: [рабочий бриф / утверждено; источник и дата]
- Формат и длина: [...]
- Цель и аудитория: [...]
- Герой и мир: [известное; что предложить]
- Жанр и основное переживание зрителя: [известное; не смешивать с форматом и тоном]
- Тон: [характер и границы]
- Обязательное / запрещено: [...]
- Артефакт: [логлайн / сцена / сценарий / пакет]
- Режим работы: [быстрый / разработка / пакет]
- Оценка по брифу: [рубрика, если дана]
- Допущения и открытые вопросы: [...]
```

Для серии добавь описание связи и движка из `short-form-series.md`. Не задерживай обсуждение, если движок ещё не найден: покажи варианты или назови нерешённое.

Для жанровой истории выбери относящиеся к брифу инструменты из `genre-promises.md`. Запрос на широкую аудиторию не означает отказ от жанровой специфики; без зрительских данных не обещай массовую привлекательность.

## Идея и инсайт

Приём для рекламы, адаптированный из creative-director-skill (Serge Shima, CC BY 4.0): «[аудитория] хочет [X], но [Y мешает], потому что [Z]». Возможные напряжения: культурное, категорийное, человеческое. Утверждение об аудитории без исследования помечай гипотезой.

В художественной истории можно начать с образа, противоречия героя, ситуации или финала. Не требуй рекламного инсайта для каждого жанра.

Предлагай обычно 3–5 существенно разных вариантов, когда пользователь выбирает концепцию. Оцени по конкретности, соответствию брифу, неожиданности, эмоциональной ставке и реализуемости. Не отбрасывай идеи из-за порядкового номера и не имитируй объективную оценку оригинальности.

Логлайн — предпочтительно одно предложение: `[герой] стремится к [цели], но [препятствие] вынуждает его [выбор], рискуя [ставкой]`. Это опора, не обязательная формула для бессюжетного клипа. В питче интригу финала можно сохранить; в рабочем плане развязка должна быть понятна.

## Вход на нужный этап

| Запрос | Действие |
|---|---|
| Придумай | Варианты с кратким основанием и рекомендованным направлением |
| Создай мир или героя | Только нужные части CANON / паспорта |
| Напиши сценарий | Бриф → биты → сцены; шоты, если нужны по запросу |
| Исправь | Определи масштаб правки, сохрани остальное, проверь последствия |
| Оцени | Конкретное место → проблема → эффект → предлагаемая правка; не переписывай без запроса |
| Подготовь к производству | Шоты, речь, инварианты, версии, handoff и READOUT |

Утверждённое не переосмысляй без команды. Если новая команда явно меняет решение, внеси её и отрази последствия. При конфликте двух обязательных условий сохрани оба в реестре как `blocked`, объясни конфликт и предложи варианты.

## Director's review

Применяй только относящиеся к артефакту проверки; для каждой находки укажи конкретный бит/сцену/реплику.

| Проверка | Вопрос |
|---|---|
| Обещание | Что заинтересует эту аудиторию и выполнено ли обещанное? |
| Причинность | Понятно, почему действие приводит к следующему событию? |
| Герой | Чего хочет, что выбирает, что теряет или приобретает? |
| Видимость | Какие смысловые вещи можно увидеть/услышать; где VO лишь пересказывает кадр? |
| Ритм | Помещаются действие, реакция, речь и паузы в длину? |
| Функция | Что потеряется без бита — информация, эмоция, ориентация, ритм или следствие? |
| Бриф | Соблюдены ли ограничения и актуальные правки? |
| Серия | Тип связи соблюдён, есть содержательное отличие от других эпизодов? |
| Continuity | Совпадают ли нужные состояния, знания, реквизит и направления? |
| Производство | Что требует проверки производственным скиллом? Не объявлять возможности модели проверенными |

Отдельные проходы редактуры — `screenwriting-craft.md`. Для быстрого запроса не выдавай весь чеклист: сообщи только значимые выводы.
