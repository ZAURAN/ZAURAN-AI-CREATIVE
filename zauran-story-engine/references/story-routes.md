# Маршруты, бриф истории и контрольные точки

## Нулевая фаза

До вопросов выпиши из чата, вложений и названных папок:

- что за продукт истории: реклама / сюжетный ролик / сериал коротких эпизодов / клип / вселенная под серию контента;
- формат и хронометраж (6 / 15 / 30 / 60 с / длиннее / без ограничения);
- кто аудитория и какой один эффект нужен (эмоция, действие, узнавание);
- что уже есть: герои, локации, референсы, старые сценарии, CANON.md, паспорта;
- что запрещено (бренд, эпоха, персонажи, сюжетные ходы, тон);
- куда сохранять;
- **критерии оценки**, если бриф — тест/тендер/конкурс с баллами: выписать рубрику дословно с весами в STORY LOCK как строку «Оценка: …» и на каждой контрольной точке спросить «какой пункт рубрики это даёт». Пункт с максимальным весом определяет движок, а не тон.

Раздели на четыре группы: подтверждено пользователем / из референса / гипотеза / неизвестно. Не спрашивай то, что уже ясно.

## STORY LOCK

Перед написанием структуры покажи компактный блок и получи «делай», если не дано явно:

```md
## STORY LOCK
- Формат: [реклама 30 с 9:16 / серия 6 эпизодов по 20 с / …]
- Цель: [одно предложение — что зритель должен почувствовать или сделать]
- Аудитория: [кто, что его злит, чего хочет]
- Герой: [есть / создать / несколько]
- Мир: [реальный / стилизованный / придуманный — нужен ли CANON]
- Тон: [3 прилагательных + 1 анти-прилагательное]
- Обязательное: [продукт, CTA, реплика, локация]
- Запрещено: [что не добавлять]
- Финальный артефакт: [логлайн / CANON / паспорта / сценарий / шот-лист / полный пакет]
- Куда: [папка]
- Оценка (если бриф с рубрикой): [пункт — вес, дословно; что в пакете закрывает каждый]

## SERIES SCALE  (только для серии / повторяющегося героя — обязателен, шаблон и гейт в `short-form-series.md`)
- Движок (без локации и времени): [...]
- Архетип: [...]
- Оси вариативности (≥3): [...]
- Константы (≤5): [...]
- 10 эпизодов за 5 минут: [...]
- Карта локаций (≥5): [...]
- Люди в кадре (≥5 из 10): [...]
- Причина поделиться: [...]
- Петля между эпизодами: [...]
```

Для серии STORY LOCK без заполненного SERIES SCALE пользователю не показывается.

## Режимы

| Режим | Вход | Выход |
|---|---|---|
| **Идея → логлайн** | тема, продукт, «придумай» | 3–5 логлайнов с инсайтом, рекомендованный первым |
| **Вселенная** | серия контента, повторяющийся мир | `CANON.md` — см. `story-bible.md` |
| **Персонаж** | герой на несколько роликов/кадров | `PASSPORT_<имя>.md` — см. `character-passport.md` |
| **Структура** | утверждённый логлайн | каркас + бит-лист по таймингу — `structure-and-beats.md` |
| **Сцена** | бит или драматическая ситуация | сцена через Scene Engine + causal audit |
| **Шот-сценарий** | утверждённые сцены | `SCRIPT_vN.md`: шоты 1–3 с, камера, звук, инварианты — `scene-to-shotlist.md` |
| **Диалог / VO** | сцена или бит-лист | реплики + режиссура — `dialogue-and-vo.md` |
| **Аудит** | чужой/старый сценарий | что не работает по битам, сценам, continuity, чем чинить |
| **Handoff** | всё утверждено | пакет для `zauran-ai-creative` — `handoff-to-production.md` |

Выбирай только нужные. Для 15-секундной рекламы CANON не нужен; для серии из 6 эпизодов обязателен.

## Контрольные точки

1. Story lock.
2. Логлайн + инсайт утверждены.
3. CANON / паспорта утверждены (если нужны).
4. Каркас + бит-лист утверждены.
5. Сцены прошли causal audit.
6. Шот-сценарий + VO утверждены.
7. Handoff-пакет собран, файлы на месте.

Меняй один смысловой блок за итерацию. Не перепридумывай утверждённое.

## Идея и инсайт

Адаптация из creative-director-skill (Serge Shima, CC BY 4.0).

- Сначала инсайт, потом идея. Формат инсайта — одно предложение: **«[аудитория] хочет [X], но [Y мешает], потому что [Z]»**.
- Найди одно напряжение: культурное (что общество говорит vs делает), категорийное (что категория обещает vs даёт), человеческое (чего хочет человек vs что мешает).
- Тест инсайта: услышав, человек говорит «да, точно, но я так никогда не формулировал».
- Первые 5 идей — клише. Отбрось. Настоящая работа после пятой.
- Simplicity as violence: идея объясняется одним предложением, иначе она не идея.
- Клиент/зритель — герой, бренд — проводник. Бренд-герой теряет аудиторию.

### Логлайн

`[Герой с определяющей чертой] должен [цель], но [препятствие], иначе [ставка]. [Что меняется в финале].`

Дай 3–5 вариантов с разными напряжениями, не 5 перефразировок одного.

## Director's review (перед структурой и перед handoff)

| Проверка | Что искать |
|---|---|
| Гачок | Что зритель видит в первые 1–2 секунды? |
| Ясность | Можно ли показать смысл, а не объяснять VO? |
| Изменение | Что стало другим от первого до последнего шота? |
| Производимость | Реально ли собрать это отдельными контролируемыми клипами? |
| Continuity | Что обязано совпасть между шотами? |
| Бриф | Не добавили ли чужой сюжет, стиль, реквизит, эпоху? |
| Pixar-фильтр | Показана борьба, а не результат? У героя есть позиция? Можно убрать сцену без потери? Это первая идея или десятая? |
| Скролл-тест (соцсети) | Первые 2 с без звука: картинка + текст объясняют, зачем смотреть? Образ меняется каждые 2–3 с? |
| Масштаб (серия) | 10 названий из движка, ≥5 локаций, ≥3 разных людей в кадре, константы переносятся в любое место? Ни одно правило CANON §3 не запирает место/время/собеседника? |
| Второе лицо | Есть ли в эпизоде кто-то кроме героя — человек, голос с лицом, тело антагониста? |

## Что запрещено

- Добавлять героя, продукт, реплику, реквизит, эпоху, культуру, сюжетный поворот без основания в брифе.
- Заменять точечную правку полной перегенерацией истории.
- Называть вариант «утверждённым» без подтверждения пользователя.
- Обещать возможности модели (lip-sync, длительность, физика) — это проверяет `zauran-ai-creative`.
- Писать промт под модель. Граница скилла — сценарий, канон, шот-лист. Промт — handoff.
