# Паспорт персонажа — PASSPORT_<имя>.md

Две половины. **Визуальная** — чтобы герой совпадал между кадрами и генерациями. **Драматическая** — чтобы герой действовал, а не позировал. Для повторяющегося драматического героя нужны обе; для маскота без психологической арки достаточно поведения и визуальных признаков. Для одноразового статиста хватает строки в сцене.

## Шаблон

```md
# PASSPORT — [Имя]
ID: CHAR_<имя> · Версия: v1 · Роль в мире: [герой / антагонист / проводник / маскот]

## A. Визуальные инварианты  (LOCKED — точный блок для разворачивания при передаче в производство)
- Возраст, пол, телосложение, рост относительно других: [...]
- Лицо: [форма, глаза, брови, нос, губы, кожа, особые приметы]
- Волосы: [цвет, длина, форма, как лежат]
- Неизменная одежда/детали, если требуются брифом: [цвета, материалы; иначе одежда в §B]
- Аксессуары-сигнатуры: [1–3 предмета, по которым узнают]
- Палитра героя: [2–3 цвета]
- Пластика: [как стоит, ходит, жестикулирует — одно-два наблюдаемых движения]
- Голос (для VO / диалога): [тембр, темп, регистр — без имитации реального человека]

## B. Что может меняться  (FLEX)
- Одежда по умолчанию и разрешённые варианты: [...]
- [причёска / настроение / …]; конкретное состояние — в сцене

## C. Драматическое ядро
- Хочет (want, внешняя цель): [...]
- Нуждается (need, внутренняя правда, которую не видит): [...]
- Рабочее убеждение / противоречие: [...]
- Прошлый опыт, если влияет на решения: [...]; травма не обязательна
- Позиция / мнение (о чём спорит с миром): [...]
- Чего боится: [...]
- Как принимает решения под давлением: [...]

## D. Тактики (как действует, когда цель под угрозой)
1. Первая реакция: [...]
2. Если не сработало: [...]
3. Крайняя мера: [...]

## E. Речь
- Длина фраз: [короткие / рубленые / длинные]
- Любимые слова / что никогда не говорит: [...]
- Пример реплики в спокойствии: «…»
- Пример реплики под давлением: «…»

## F. Отношения
| С кем | Что хочет от него | Что скрывает |
|---|---|---|

## G. Референсы
- Turnaround sheet: `[путь к файлу]` (см. ниже как получить)
- Фото-референсы: `[путь]` — роль: только внешность / только пластика / только одежда

## H. Журнал
- YYYY-MM-DD — v1
```

## Как получить визуальный паспорт

Секция **A** пишется текстом первой. Затем — turnaround sheet через `storyboard-templates.md` § «Character turnaround sheet» (промт под изображение; модель и генерацию выбирает `zauran-ai-creative`). После утверждения листа его путь фиксируется в §G, и лист становится референсом роли «персонаж» во всех последующих промтах.

В сценарии ссылайся на `CHAR_<имя>@vN` и состояние сцены (одежда, реквизит, настроение). Точный §A и референс приложи в handoff; при необходимости производственный скилл разворачивает §A без перефразирования. Текстовый инвариант снижает расхождения описаний, но не гарантирует совпадение генераций.

## Связь с игрой

Для сцены с диалогом, реакцией, слушанием — секции C, D, E конвертируются в ACTING TASK по `../../references/tig-acting-task.md` (путь от этого reference-файла). Если модуль отсутствует, опиши цель в моменте, действие, реакцию и новую тактику по `screenwriting-craft.md`. Паспорт даёт «кто», Acting Task даёт «что делает прямо сейчас».
