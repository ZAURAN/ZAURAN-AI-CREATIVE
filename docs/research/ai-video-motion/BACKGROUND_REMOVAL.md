# Качественное удаление фона

Начальный локальный вариант — [rembg](https://github.com/danielgatis/rembg): библиотека/CLI, поддержка разных моделей, alpha matting и обработка края. Для сложных фото сравнить подходящие веса [BiRefNet](https://github.com/ZhengPeng7/BiRefNet) на собственных кадрах. Нельзя заранее назвать модель лучшей для всех волос, товаров, стекла и рисунков.

Приложен `scripts/remove_background.py`: локальный wrapper сохраняет исходник, требует новый PNG, проверяет существование файлов и ограничивает модели. При первом запуске rembg может скачать веса. Сейчас скрипт не запускался на фото, модели и зависимости не устанавливались.

Пример в отдельном окружении:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install "rembg[cpu]" pillow
.\.venv\Scripts\python scripts/remove_background.py photo.jpg cutout.png --model birefnet-general --alpha-matting
```

Если alpha matting ухудшает мягкие детали, повторить без флага и сравнить результат. Проверить масштаб 100–200%, белый, чёрный и насыщенный фон; волосы, пальцы, стекло, полупрозрачную одежду, отверстия и тени. Отдельно сохранять mask/alpha, исходник, используемую модель, версию и результат QA в реестре ассетов. Частичное удаление чужого объекта требует маски с указанием нужного предмета, а не только общей сегментации.

Для сложного композитинга не кодировать промежуточный результат в обычный H.264 — прозрачность потеряется. Сохранять PNG/последовательность либо поддерживаемый пайплайном формат с alpha; проверить premultiplied/straight alpha, чтобы не получить тёмный ореол.

[SAM 2](https://github.com/facebookresearch/sam2) пригоден для масок и отслеживания в видео, но отслеживаемая сегментация не равна аккуратному alpha matting. Покадровая обработка фото-моделью может мерцать, для видео нужен контроль временной стабильности. [BRIA RMBG-2.0](https://huggingface.co/briaai/RMBG-2.0) требует отдельной проверки лицензии весов и коммерческих условий: лицензия wrapper-репозитория не даёт автоматически прав на все подключаемые модели.

Выбор в ZAURAN: editorial planner отмечает `needs_cutout`; asset-processing создаёт производный ассет; video-review принимает края; motion-composer получает только зарегистрированный результат со статусом QA. Никаких автоматических обещаний «качественно» без визуальной приёмки.
