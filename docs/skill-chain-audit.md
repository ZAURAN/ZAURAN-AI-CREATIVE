# Аудит передачи между скиллами — 2026-10-16

## Область

Проверены восемь точек входа: ai-creative, story-engine, character-forge, scene-director, context-guard, voice-director, video-studio, ae-brief-director; связанные правила handoff, паспортов, костюмов, раскадровки, версий, TTS и восстановления контекста. Это статический аудит инструкций и контрольных сценариев перехода, не проверка точности медиагенераторов или актуальности всех API моделей. Вендоренные корпуса не переписывались.

## Исправления

- Первый лист персонажа: карта лица, затем нужная карта одежды; старый сложный turnaround только как дополнительный заказанный материал.
- Шаблоны раскадровки не меняют число шотов, действия, утверждённую камеру и финал сценария.
- IDENTITY LOCK отделён от одежды и состояния конкретной сцены; постоянный костюм фиксируется только при таком требовании.
- Передаются применимые поведение/контекст паспорта, ID, версия, статус выбора, референсы и открытые вопросы.
- Утверждённые бренды/надписи не удаляются общим запретом самовольных логотипов.
- Исходные LOCK сохраняются вместе с проверенной английской формулировкой; точная речь и надписи не переводятся.
- Нечеловеческая анатомия и выбранный стиль не заменяются человеческим фотореалистичным шаблоном.
- Архивные handoff получают уникальные папки; старые версии паспортов разрешаются по точным ID/версиям.
- Высший номер файла не означает утверждение; текущие промпты и модели выбираются отдельно по ассету/шоту/типу медиа.
- Смена модели допускает необходимое изменение структуры без удаления требований и негативов.
- Общий контракт содержит проверку приёма источников, полноты требований и обновления зависимостей; сохранение новых файлов предшествует обновлению STATE.
- Проектный TTS-промпт сохраняется в Markdown/PDF; обычная консультация, паспорт и модель-независимое ТЗ не становятся промптами автоматически.
- Чекпоинт не отменяет новые теги; актуальные таблицы восстанавливаются из живого STATE и источников.
- AE принимает точную версию сценария и реестр; video-studio предпочитает действующие ZAURAN-контракты архивному snapshot.
- Общие советы по динамике, длине негативов и расширению клипа не отменяют сценарий или границы поручения.
